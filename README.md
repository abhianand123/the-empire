## ⚡ Technical Architecture

- **Natural Vertical Scrollytelling**: Seamless full-page document scrolling with background video scrubbing and crossfading across 4 cinematic milestones.
- **Ultra-Translucent Glassmorphism**: High-performance backdrop-filter blur effects with dark theme aesthetic.
- **Hardware-Accelerated Seek Coalescing**: Throttled video decode loops on mobile devices and Blob prefetching to eliminate network byte-range stalls.
- **Pure Vector UI**: Zero-dependency inline SVGs for all brand icons and social links.

## 🚀 Quickstart & Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production (Vercel Ready)
```bash
npm run build
```

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub.
2. Import the project into [Vercel](https://vercel.com).
3. Vercel will automatically detect Vite and run `npm run build` with output directory `dist`.
4. Deploy!
